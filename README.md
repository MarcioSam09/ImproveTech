# TechXugo: Landing Page

Site institucional da TechXugo (ex-Improve Tech): agência de tecnologia e
marketing digital formada por programadores. A gente cava até resolver.

## Stack

HTML + CSS + JavaScript puros, sem build e sem dependências. A única
requisição externa é a fonte Inter (Google Fonts).

## Estrutura

```
index.html    conteúdo e marcação
styles.css    identidade visual (dark #0A0D12 + verde-volt #C9F73A + cream)
script.js     interações (typewriter, reveal on scroll, tilt 3D, menu mobile)
assets/       screenshots de cases e fotos dos sócios
```

## Rodando local

Abrir `index.html` no navegador. Pronto.

## Deploy

Estático puro, funciona em Netlify, Vercel ou GitHub Pages sem configuração:
basta apontar pro diretório raiz do repositório.
